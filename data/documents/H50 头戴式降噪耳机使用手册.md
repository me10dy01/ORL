# 星辰 H50 头戴式降噪耳机使用手册

## 一、产品规格

| 参数 | 规格 |
|------|------|
| 型号 | XCH-H50 |
| 类型 | 头戴式主动降噪耳机 |
| 驱动单元 | 40mm 钕磁铁动圈 |
| 频率响应 | 20Hz - 40kHz |
| 降噪深度 | -35dB（主动降噪） |
| 蓝牙版本 | 5.3 |
| 支持编解码 | AAC / SBC / LDAC |
| 电池 | 1000mAh 锂电池 |
| 续航 | ANC 开启约 30 小时，ANC 关闭约 45 小时 |

| 折叠 | 支持折叠，附赠收纳盒 |

## 二、按键与操控

| 位置 | 操作 | 功能 |
|------|------|------|
| 右耳罩 - 电源键 | 长按 2 秒 | 开机/关机 |
| 右耳罩 - 电源键 | 短按 | 播放/暂停 |

| 右耳罩 - 音量旋钮 | 旋转 | 调节音量 |

## 三、连接方式

### 蓝牙连接
1. 长按电源键 2 秒开机，指示灯蓝白交替闪烁进入配对模式。
2. 在设备蓝牙列表中选择"XCH-H50"完成配对。
3. 支持蓝牙多点连接：可同时连接 2 台设备，来电时自动切换到手机。

### 有线连接
1. 使用附赠的 3.5mm 音频线连接耳机和设备。
2. 有线模式下无需开机即可使用（被动模式）。
3. 有线模式下主动降噪功能不可用。

## 四、降噪模式说明

1. **主动降噪（ANC）**：最大 -35dB 降噪，适合地铁、飞机、办公室等嘈杂环境。
2. **通透模式**：拾取环境音并混入耳机，不摘耳机也能听到周围声音和对话。
3. **关闭**：仅被动隔音，最省电。

## 五、充电说明

1. 使用 USB-C 充电线充电，建议使用 5V/1A 或 5V/2A 充电器。
2. 充电时指示灯红色常亮，充满后熄灭。
3. 快充：充电 10 分钟可使用约 3 小时。
4. 电量低于 10% 时，语音提示"电量低"。

## 六、保养建议

1. 耳罩为蛋白质皮材质，避免长时间阳光直射。
2. 不使用时放入收纳盒，避免挤压变形。
3. 耳罩和头梁垫为消耗品，可在商城单独购买替换。
4. 避免在极端温度（低于 -10°C 或高于 45°C）下使用。

## 七、故障排除

| 问题 | 解决方法 |
|------|----------|
| 蓝牙连不上 | 长按电源键 5 秒重置蓝牙；清除设备配对记录重新配对 |
| 降噪效果差 | 检查耳罩是否完全包裹耳朵；清洁耳罩缝隙 |
| 一边没声音 | 检查音源平衡设置；尝试有线模式排除蓝牙问题 |
| 充电不进电 | 更换充电线；清洁充电口 |
| 通话对方听不清 | 检查麦克风孔是否被遮挡；在安静环境测试 |

## 八、保修信息

1. 整机保修 **2 年**。
2. 保修范围：非人为损坏的功能故障（降噪模块、蓝牙模块、电池等）。
3. 不在保修范围：人为损坏、耳罩和头梁垫磨损、线材损坏。
