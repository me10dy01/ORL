# 星辰数码商城售后服务与保修政策

本商城为在售商品提供规范的售后服务与保修保障。顾客凭订单号与购买凭证即可享受相应服务。

## 一、售后时效总览

| 服务项 | 时效 | 说明 |
| --- | --- | --- |
| 无理由退货 | 签收后 7 天内 | 商品完好，运费买家承担 |
| 质量问题退换 | 签收后 15 天内 | 运费商城承担 |
| 保修 | 见下表 | 非人为损坏免费维修 |

## 二、保修期限

| 商品类别 | 保修期限 |
| --- | --- |
| 键盘 | 1 年 |
| 鼠标 | 1 年 |
| 耳机 | 2 年 |
| 显示器 | 3 年 |
| 移动电源 | 1 年 |
| 音箱 | 1 年 |
| 充电器 | 6 个月 |
| 数据线 | 6 个月 |
| 手机支架等配件 | 3 个月 |

示例：星辰 H50 降噪耳机保修期为 2 年；星辰 K87 机械键盘保修期为 1 年；星辰 M27 电竞显示器保修期为 3 年。

## 三、保修范围

1. 保修仅针对非人为损坏的质量问题（如电路故障、按键失灵、接口接触不良等）。
2. 因跌落、进水、私自拆修、超负荷使用等人为原因造成的损坏不在保修范围内。

申请售后时请提供：订单号、商品照片或视频、问题描述。缺少必要材料可能导致审核延迟。
