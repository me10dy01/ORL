# 星辰 K87 三模机械键盘使用手册

## 一、产品规格

| 参数 | 规格 |
|------|------|
| 型号 | XCK-K87 |
| 连接方式 | 蓝牙 5.0 / 2.4G 无线 / USB-C 有线 |
| 轴体 | 星辰自研红轴（热插拔） |
| 键帽材质 | PBT 双色注塑 |
| 按键数量 | 87 键（TKL 布局） |
| 背光 | RGB 16.8M 色，支持多种灯效模式 |
| 电池 | 4000mAh 锂电池 |
| 续航 | 背光关闭约 200 小时，背光开启约 30 小时 |
| 重量 | 约 850g（不含线） |
| 尺寸 | 358 x 132 x 38mm |
| 兼容系统 | Windows / macOS / Linux / Android / iOS |

## 二、连接方式

### 蓝牙连接
1. 长按 Fn+Q（或 Fn+W / Fn+E）3 秒，对应指示灯快闪进入配对模式。
2. 在设备蓝牙列表中选择"XCK-K87"完成配对。
3. K87 最多记忆 3 台蓝牙设备，Fn+Q/W/E 快速切换。

### 2.4G 无线连接
1. 将 2.4G 接收器插入电脑 USB 口。
2. 键盘背面开关拨至 2.4G 位置，自动连接。

### 有线连接
1. 使用附赠的 USB-C 数据线连接键盘和电脑。
2. 有线模式下自动充电，同时可正常使用。

## 三、快捷键说明

| 组合键 | 功能 |
|--------|------|
| Fn + F1~F3 | 蓝牙设备 1/2/3 |
| Fn + F4 | 2.4G 模式 |
| Fn + F5 | 有线模式 |
| Fn + 方向键 | 背光亮度/速度调节 |
| Fn + Space | 恢复出厂背光设置 |
| Fn + Del | 截屏键（Windows） |
| Esc + 电源键长按 5 秒 | 恢复出厂设置 |

## 四、充电说明

1. 充电时键盘可正常使用。
2. 电量低于 10% 时，电源指示灯红灯闪烁提醒。
3. 充电约 3 小时充满，充满后指示灯绿灯常亮。
4. 建议使用 5V/2A 充电器，避免使用快充头。

## 五、保养建议

1. 避免液体溅入键盘，若不慎进水立即断电并倒置晾干。
2. 定期用毛刷清理键帽间灰尘。
3. 更换轴体时确认方向正确，避免损坏轴座。
4. 长期不使用时建议关闭电源开关。

## 六、故障排除

| 问题 | 解决方法 |
|------|----------|
| 蓝牙连接不上 | 长按 Fn+Q 进入配对模式；重置键盘（Esc+电源键 5 秒） |
| 按键无响应 | 检查是否切换到正确模式；尝试换轴；有线连接测试 |
| 充电不进电 | 更换数据线和充电头；检查充电口是否有灰尘 |
| 按键连击 | 清洁轴体；尝试更换轴体；若保修期内可申请售后 |
| 2.4G 延迟高 | 检查接收器是否被金属遮挡；更换 USB 口 |

## 七、保修信息

1. 整机保修 **1 年**，轴体保修 **2 年**。
2. 保修范围：非人为损坏的功能故障。
3. 不在保修范围：人为损坏（进液、摔落、拆机）、键帽磨损、外观划痕。
4. 保修需提供购买凭证（订单号或发票）。
